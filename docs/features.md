# Planned features

Here is a list of features that are planned for future releases of the project. These features are currently under consideration and may be implemented in upcoming versions.
1. **Edit Restaurant Details**: Allow users to edit restaurant information, such as name, address, cuisine type, and contact details, to keep the data up-to-date.
2. **E2E Testing**: Implement end-to-end testing using Playwright to ensure the application works as expected from the user's perspective.
